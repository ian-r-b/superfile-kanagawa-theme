Kanagawa Theme for Superfile
============================
A Kanagawa theme for Superfile, adapted from the `catppuccin-mocha` theme by AnshumanNeon.

To install, use the commands from below or put `kanagawa.toml` into `~/.config/superfile/theme/`
```
git clone https://github.com/ian-r-b/superfile-kanagawa-theme

cd superfile-kanagawa-theme

cp kanagawa.toml ~/.config/superfile/theme/
```
